# Geometry fixtures

- `iox-overlap` reproduces the coordinates and model of the XTF 2.3 AREA regressions from iox-ili. The `Area_1Boundary_NoOverlap` and `Area_2Boundaries_NoOverlap` headers use the version declared in `Overlap23.ili`. Where necessary, ARC elements use the normative order with `C1` and `C2` preceding `A1` and `A2`. The iox-ili MIT text is included in `iox-overlap/LICENSE.mitx`. [Pinned model and transfers](https://github.com/claeis/iox-ili/tree/ae42877035ce029fec453cc5e51966e0a8a3f941/src/test/data/Xtf23Overlap)
- `NoiseZones` uses the two reported boundaries with TIDs 188 and 369 in a minimal local model. The fixtures reproduce those geometric facts from the public issue attachment. The issue gives no separate license for the archive. [ilivalidator #468](https://github.com/claeis/ilivalidator/issues/468) · [iox-ili fix and comparison test](https://github.com/claeis/iox-ili/pull/166)
- `ThinStraightGap` uses the three reported decimal vertices and closes the two surfaces with local outer edges. The intermediate vertex on the longer route is strictly off the direct segment. The triangle between them has area `0.000505` square coordinate units. [ilivalidator #376](https://github.com/claeis/ilivalidator/issues/376)
- `NearArcOverlap` uses four coordinate pairs published in the issue body. A locally authored model and transfer join the reported straight and first arc into one polyline. The second exact-geometry intersection lies about `0.000433336` coordinate units from their common endpoint. [ilivalidator #476](https://github.com/claeis/ilivalidator/issues/476)
- The curved `CoverageGaps` transfers use literal coordinates from the iox-ili test methods in a local model. `GapAfterToleratedOverlap` leaves an enclosed opening, `OverlapOpenToOutside` connects the residual region to the exterior, `EnclaveWithToleratedOverlap` leaves a residual region within an interior ring, and `GapBetweenArcAndStraight` encloses a region with a circular arc and its chord. The iox-ili MIT text is included in `iox-overlap/LICENSE.mitx`. [Coverage fixes for #162](https://github.com/claeis/iox-ili/commit/414ff4c002d256a5471ca8f921f4250179acd1db) · [Arc-and-chord case](https://github.com/claeis/iox-ili/blob/ae42877035ce029fec453cc5e51966e0a8a3f941/src/test/java/ch/interlis/iox_j/validator/AreAreasWithoutGaps24Test.java#L120)
